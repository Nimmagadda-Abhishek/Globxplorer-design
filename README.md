# Globxplorer Design

Globxplorer Design is a front-end web application built from a Figma design for an education and visa management platform. It showcases a modern dashboard and workflow interface for managing students, leads, alumni, agents, counsellors, notifications, reports, and business operations.


## Project overview

- Built with React, TypeScript, and Vite
- Styled using Tailwind CSS
- Includes role-based management screens for students, agents, counsellors, and managers
- Focused on education consultancy and visa processing workflows

## Main features

- Dashboard and analytics pages
- Student and alumni management views
- Lead pipeline and follow-up tracking
- Agent and manager panels
- Notifications, messages, reports, and settings screens
- Responsive, modern UI for business operations

## Getting started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```

3. Open the local URL shown in the terminal to view the app in your browser.

## Notes

This project is mainly a front-end UI implementation and design prototype. It is intended to present the Globxplorer platform experience and interface flow, rather than a fully connected backend system.
